# Prosty wzór kontekstu firmy

Przy wskazanym formularzu pozostaw tylko potrzebne pola. To przykład
układu, nie obowiązkowy schemat.

```markdown
# Kontekst firmy — [nazwa]

| Dane | Wartość |
| --- | --- |
| Pełna nazwa | … |
| KRS | … |
| NIP | … |
| REGON | … |
| Siedziba i adres | … |
| Osoby uprawnione do reprezentacji i stanowiska | … |
| Zasada reprezentacji | … |
| Strona WWW | … |
| Telefon | … |
| E-mail | … |
| Krótki opis działalności | … |

Data zebrania: [RRRR-MM-DD]

Źródła:
- KRS: [link]
- Strona firmy: [link]
```
